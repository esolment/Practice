### Циклы и массивы

Код в `LoopsAndArrays.cs`.

`LoopsAndArrays.Run(interactive)` вызывается из `Program.cs`: `true` - данные вводит пользователь, `false` - данные выбираются случайно.

#### Итоговый проект «Склад экспедиции»

Массив `warehouses` из 10 складов заполняется случайными числами 0-10.

Алгоритмы (один проход `for` по массиву):
- **Сумма** - накапливается в `totalSum`.
- **Минимум / максимум** - стартуют с `warehouses[0]`, обновляются при нахождении меньшего/большего.
- **Пустые склады** - счётчик элементов, равных 0.
- **Поиск** - цикл `while`: читает запрос, линейным `for` ищет первый склад с таким количеством, при неудаче выводит ошибку. Выход - `exit`.

#### Остальные задания

В интерактивном режиме пользователь вводит данные в заданиях 4, 5, 6, 12, 17, 18, 21 и в поиске по складам (ввод проверяется функцией `ReadInt`). В режиме `false` те же значения берутся случайно. Остальные задания работают на заданных массивах или `Random`.
