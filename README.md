## Документация по темам

### Циклы и массивы

Код в `LoopsAndArrays.cs`.

`LoopsAndArrays.Run(interactive)` вызывается из `Program.cs`: `true` - данные вводит пользователь, `false` - данные выбираются случайно.

#### Итоговый проект «Склад экспедиции»

Массив `warehouses` из 10 складов заполняется случайными числами 0-10.

Алгоритмы (один проход `for` по массиву):
- **Сумма** - накапливается в `totalSum`.
- **Минимум / максимум** - стартуют с `warehouses[0]`, обновляются при нахождении меньшего/большего.
- **Пустые склады** - счётчик элементов, равных 0.
- **Поиск** - цикл `while`: читает запрос, линейным `for` ищет первый склад с таким количеством, при неудаче выводит ошибку. Выход - `exit`.

#### Остальные задания

В интерактивном режиме пользователь вводит данные в заданиях 4, 5, 6, 12, 17, 18, 21 и в поиске по складам (ввод проверяется функцией `ReadInt`). В режиме `false` те же значения берутся случайно. Остальные задания работают на заданных массивах или `Random`.

### Конструкторы

**Задача 20. Сборочная линия**

Консольное приложение без фреймворков: меню создания дронов трёх моделей с валидацией, счётчиком выпуска и отчётом в виде `record`.

#### Иерархия

```
Drone (abstract)
├── ScoutDrone   — Range (дальность)
├── CargoDrone   — Capacity (грузоподъёмность)
└── MedicDrone   — Kits (аптечки)
```

- `Drone` хранит `Serial`, `Energy`, `Id` и static-счётчик `CreatedCount`.
- Конструктор `Drone` валидирует серийник (не пустой) и энергию (0–100). Выход за границы — брак, а не `Clamp`.
- Каждая модель валидирует свой параметр и передаёт общие данные через `base(serial, energy)`.
- Перегрузки строятся цепочкой `this(...)`: `(serial)` → `(serial, energy)` → `(serial, energy, параметр)`.

#### Счётчик

`CreatedCount` увеличивается методом `Commit()`, который вызывается последней строкой конструктора модели, после всей валидации. Поэтому бракованный дрон в счётчик не попадает.

#### Лицензия

`License.TryParse(key)` — фабрика с приватным конструктором. Ключ: ровно 8 символов, только буквы и цифры. При неверном ключе линия не запускается.

#### Отчёт

`Report(Serial, Model, Energy, CreatedUtc)` — `record`, создаётся через `Report.From(drone)` после успешной сборки. Пункт меню «Выгрузить отчёт» выводит все записи.

#### Меню

| Пункт | Действие |
|-------|----------|
| 1 | Создать scout |
| 2 | Создать cargo |
| 3 | Создать medic |
| 4 | Показать `CreatedCount` и число отклонённого брака |
| 5 | Выгрузить отчёт |
| 0 | Выход |

#### Брак

Невалидные данные (пустой серийник, энергия вне 0–100, неположительная дальность, отрицательное число аптечек, нечисловой ввод) вызывают исключение. Оно перехватывается в `Assemble`, дрон отклоняется, счётчик брака растёт.

#### Запуск

```csharp
AssemblyLine.Run();                      // интерактивное меню
AssemblyLine.Run(debug: true);           // с логом конструкторов
AssemblyLine.Run(interactive: false);    // демо без пользовательского ввода
```

При `interactive: false` ввод с консоли не читается вообще: используется тестовая лицензия `DEMO1234`, собираются три дрона, затем два бракованных (пустой серийник и энергия 150), после чего выводятся счётчики и отчёт.
